# Backlog Management

When starting a session with no explicit user task:
1. Read `.claude/BACKLOG.md` to gain context of project backlog.

When completing work:
1. Check off the item in BACKLOG.md.
2. Move it to the Completed section with date and commit/PR ref.
3. If new work was discovered, add it to the appropriate priority tier.

When committing or creating a PR:
1. Before finalizing, verify the relevant BACKLOG.md item is checked off and moved to Completed.
2. Backlog updates should be included in the same commit or PR that delivers the work — not deferred to a later session.
